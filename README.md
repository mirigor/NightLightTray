# NightLight Tray

Приложение для Windows 11: ползунок интенсивности штатного «Ночного света» в системном трее.
Без собственных цветовых фильтров и гамма-коррекции.

## Установка

Скачайте репозиторий архивом ZIP или клонируйте его, затем запустите
`NightLightTraySetup.exe` двойным кликом и следуйте мастеру. Установщик хранится
в корне репозитория вместе с исходниками.
Python, Node.js, Rust и права администратора не нужны.

По умолчанию приложение устанавливается в `%LOCALAPPDATA%\Programs\NightLightTray`.
Папку можно изменить в мастере установки. Мастер добавляет ярлык в «Пуск».
Если приложение уже установлено, для смены папки сначала удалите старую установку.
Для работы без установки можно собрать переносной `NightLightTray.exe` по инструкции ниже.

Для обновления запустите новый установщик. Перед установкой или удалением закройте
приложение через «Выход» в меню трея.
Удаление: «Параметры Windows → Приложения → Установленные приложения → NightLight Tray».

Сборки пока без цифровой подписи — Windows может предупредить о неизвестном издателе.

## Использование

- Левый клик по луне открывает ползунок; повторный клик или клик вне окна закрывает его
- Интенсивность: 0–100%, колёсико — шаг 2%, стрелки клавиатуры — 1%
- Правый клик → «Настройки» → «Автозапуск при старте Windows» включает или выключает автозапуск
- «Выход» полностью закрывает приложение

Автозапуск по умолчанию выключен. Если значок не виден, проверьте скрытые значки трея.
В окне луна означает включённый ночной свет, солнце — выключенный.
Включение и расписание настраиваются в Windows; приложение меняет только интенсивность.
В сборке 1.0.2 обновлён компонент управления: интенсивность применяется через штатный
предпросмотр Windows, без выключения и повторного включения ночного света.

## Запуск из исходников

Нужны Windows 11 и Python **3.10**. Команды выполняются в папке проекта:

```powershell
py -3.10 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\pythonw.exe .\main.py
```

Перед запуском исходников закройте работающий EXE, иначе откроется уже запущенная копия.
Активация окружения и изменение PowerShell Execution Policy не нужны.

## Сборка

Переносной EXE:

```powershell
.\build.bat
```

Результат — `NightLightTray.exe` в корне проекта. Перед сборкой закройте его, если он работает.

Для установщика нужен [NSIS](https://nsis.sourceforge.io/Download) 3.12 или новее:

```powershell
.\build_installer.bat "C:\Tools\nsis-3.12\makensis.exe"
```

Если NSIS установлен в стандартную папку Program Files, достаточно запустить
`build_installer.bat` без аргументов. Он собирает приложение и создаёт
`NightLightTraySetup.exe` в корне. Версия задаётся в `installer.nsi`.

Готовый установщик включён в Git, чтобы он был доступен после клонирования.
При обновлении приложения соберите его заново и добавьте новый установщик в коммит.
Переносной `NightLightTray.exe` в Git не входит; его можно создать через `build.bat`.
В Git должны оставаться `resources/`, `tools/wnl.exe` и файлы `tools/WNL_*.txt`;
окружение и временные файлы сборки исключены через `.gitignore`.

Управление Windows выполняет включённый в сборку
[win-nightlight-cli](https://github.com/kvnxiao/win-nightlight-cli) 0.4.0, лицензия MIT.
Сведения о компоненте — в [tools/WNL_SOURCE.txt](tools/WNL_SOURCE.txt).
Rust нужен только при его пересборке через `tools/build_wnl.bat`.

## Проверки

Установка инструментов разработки и Git-хука:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pre_commit install
.\.venv\Scripts\python.exe -m pre_commit run --all-files
```

Хук проверяет и форматирует код через Ruff. Если он изменил файлы, проверьте их
и повторите `git add`. После клонирования хук устанавливается заново.

Автоматические тесты не меняют настоящий ночной свет и автозапуск пользователя:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Проверка реального состояния без изменений:

```powershell
.\.venv\Scripts\python.exe .\tools\check_wnl.py
```

Опция `--write-test` временно устанавливает 56% и 68% и пытается восстановить исходное значение.
После неё проверьте восстановление. Вручную сравните ползунок с настройками Windows,
проверьте быстрые изменения, автозапуск и светлую/тёмную тему.

## Если что-то не работает

Журнал ошибок: `%LOCALAPPDATA%\NightLightTray\nightlight-tray.log`.

При ошибке чтения нажмите «Повторить чтение». Если CLI сообщает `Windows default`,
один раз измените интенсивность в параметрах Windows.
Для проверки компонента из исходников: `.\tools\wnl.exe status`.

CLI использует внутренний формат настроек Windows: обновления системы могут нарушить совместимость.
